# AI Agent Artem

AI-агент для автоматизации браузера. Выполняет сложные многошаговые задачи в вебе: заказ еды, удаление спама, поиск вакансий и любые другие задачи — полностью автономно.

Вы пишете задачу текстом, агент открывает браузер и выполняет её, а вы наблюдаете за процессом в реальном времени.

## Требования

- **Node.js** 18+
- **OpenAI API ключ** (модели: GPT-4o, GPT-4 Turbo, GPT-4o Mini)

## Установка

```bash
git clone https://github.com/Avmka1/ai-ag.git
cd ai-ag
npm install
```

`npm install` автоматически скачает Chromium для Playwright (~170 МБ).

## Запуск

```bash
npm start
```

Откроется окно приложения.

## Использование

### 1. Ввести API ключ

Вставьте ваш OpenAI API ключ в поле **OpenAI API Key** и нажмите **Save**. Индикатор станет зелёным. Ключ сохраняется между сессиями — вводить повторно не нужно.

### 2. Выбрать модель

В выпадающем списке **Model** выберите модель:
- **GPT-4o** — рекомендуется, лучшее качество + поддержка vision
- **GPT-4o Mini** — дешевле, быстрее, чуть менее точный
- **GPT-4 Turbo** — альтернатива

### 3. Написать задачу

Введите задачу в поле **Task** на естественном языке. Примеры:

```
Закажи картошку фри из "Вкусно и точка" на eda.yandex.ru
```
```
Открой hh.ru и найди 3 вакансии менеджера по продажам
```
```
Открой Gmail и удали все рекламные письма
```

### 4. Нажать Run

Нажмите **Run**. Откроется браузер Chromium, и агент начнёт выполнять задачу. В консоли приложения вы увидите:

- **[THINK]** — рассуждения агента (фиолетовый)
- **[ACT]** — выполняемое действие (синий)
- **[OBS]** — результат действия (зелёный)
- **[ASK]** — вопрос к вам (оранжевый)
- **[DONE]** — итоговый результат (зелёный жирный)
- **[ERR]** — ошибка (красный)

### 5. Взаимодействие с агентом

Если агент встретит CAPTCHA или ему понадобится дополнительная информация (логин, выбор из вариантов), появится модальное окно с вопросом. Ответьте и нажмите **Submit**.

### 6. Остановка

Нажмите **Stop** чтобы остановить агента в любой момент.

## Важно

- **Авторизация** — залогиньтесь на нужных сайтах заранее в открывшемся браузере, если задача требует аккаунта.
- **CAPTCHA** — агент автоматически определяет капчу и просит вас решить её вручную в браузере.
- **Максимум 50 шагов** — агент остановится если не уложится.

## Проверка для работодателя

В репозитории доступны оба формата проверки:

1. **Интерфейс приложения (GUI)**
   - Запуск: `npm start`
   - В окне приложения видно поле `Task`, кнопки `Run/Stop` и live-ленту логов `[THINK]/[ACT]/[OBS]/[DONE]`.

2. **Сохранённый консольный лог**
   - Файл: `logs/agent-console.txt`
   - Можно открыть любым редактором или через терминал:
     - `cat logs/agent-console.txt`

## Стек

- **TypeScript** — весь проект
- **Electron** — десктоп GUI
- **Playwright** — автоматизация браузера (headful Chromium)
- **OpenAI SDK** — GPT-4o с function calling
- **esbuild** — сборка

## Архитектура

```
Electron Window (UI)          Chromium Browser (видимый)
┌──────────────────┐          ┌──────────────────┐
│ API Key          │          │                  │
│ Task Input       │◄────────►│  Агент управляет │
│ Console (логи)   │   IPC    │  страницами      │
└──────────────────┘          └──────────────────┘
         │
    Main Process
    ├── AgentController (ReAct loop)
    ├── ToolExecutor (Playwright)
    ├── PageExtractor (compact refs)
    └── ContextManager (sliding window)
```

**ReAct-цикл**: Observe → Think → Act → повторять до завершения.

**Compact refs**: Каждый интерактивный элемент на странице получает номер `[ref:N]`. Агент ссылается на элементы по номерам — никаких захардкоженных селекторов.

**Vision**: Агент может сделать скриншот страницы и отправить его в GPT-4o для визуального анализа сложных layout'ов.

**Context management**: В контекст отправляется только **текущая** страница (в сжатом виде), а история шагов хранится как компактный лог действий/результатов. Это снижает расход токенов и помогает избегать rate limit (429 TPM) на динамичных страницах.

**find_elements()**: Отдельный tool для быстрого поиска нужных контролов по тексту/aria-label/placeholder/testid/href (например: `без соуса`, `корзина`, `оформить`) без захардкоженных селекторов.

```

├── main/
│   ├── index.ts              # Electron: окно, lifecycle
│   ├── ipc-handlers.ts       # IPC: связь UI ↔ Agent
│   └── store.ts              # Хранение API-ключа
├── agent/
│   ├── agent.ts              # ReAct-цикл, оркестрация
│   ├── tools.ts              # Tool definitions для OpenAI (navigate/click/type/.../find_elements)
│   ├── tool-executor.ts      # Исполнение через Playwright
│   ├── page-extractor.ts     # Извлечение элементов страницы
│   └── context-manager.ts    # Управление контекстом
├── renderer/
│   ├── index.html            # UI
│   ├── renderer.ts           # Логика интерфейса
│   └── styles.css            # Стили
└── preload.ts                # Electron preload
```
